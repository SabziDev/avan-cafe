## Installation

Clone the repository:

``` bash
git clone https://github.com/SabziDev/avan-cafe.git
```

Go to the project folder:

``` bash
cd avan-cafe
```

Install dependencies:

``` bash
pnpm i
```

Run the project:

``` bash
pnpm dev
```
